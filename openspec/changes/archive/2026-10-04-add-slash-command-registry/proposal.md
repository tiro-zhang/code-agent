## Why

现有斜杠命令的名称、解析、帮助、补全和执行分支分散维护，增加命令时容易出现行为不一致。建立统一注册与分发机制，让常用本地操作直接响应，并让预设提示词复用正常对话入口，为后续 Skill 系统留下清晰边界。

## What Changes

- 建立静态命令注册中心，保存名称、别名、描述、用法、类型、可选参数提示、隐藏标记和处理函数；名称及别名共享大小写不敏感的命名空间，启动时冲突立即报错退出。
- 分离解析、分发和具体终端实现。回车提交后先识别命令；空输入返回，普通消息进入 Agent，未知命令在本地提示 `/help`。
- 支持本地处理、状态操作、对话提示词三类路径。`/compact` 保留独立模型摘要及维护用量，不进入 Agent 工作循环。
- 统一帮助、别名查找和 Tab 补全的数据来源；单匹配直接补齐，多匹配显示菜单，隐藏命令不参与帮助和补全。
- 提供 `/help`、`/compact`、`/clear`、`/plan`、`/do`、`/session`、`/memory`、`/permission`、`/status`、`/review` 十个高频命令，保留 `/exit` 和 `/permissions` 兼容别名。
- `/clear` 仅清屏；`/session` 查看当前身份和项目存档列表，恢复继续使用 `--resume`；`/memory` 仅查看状态、列表及正文；`/review` 使用固定提示词，默认审查 Git 未提交改动，可指定目标。
- **BREAKING**：`/do` 改为仅返回执行模式，不再要求有效计划、不自动执行最新计划。用户切换后通过普通消息明确提交执行请求；状态栏显示 `[DEFAULT]`／`[PLAN]`，权限模式保持独立。
- 保留单行命令、`//` 转义、多行正文、流式显示、取消及授权隔离语义。不实现用户自定义命令、动态生成提示词、命令级权限控制、运行中切换会话或手工修改记忆。

## Capabilities

### New Capabilities

- `slash-commands`：命令元数据、静态注册与启动校验、解析分发、界面无关接口、统一帮助补全及内置命令合同。

### Modified Capabilities

- `interactive-chat`：注册驱动的命令入口、补全菜单、清屏、状态栏模式标记及 `/do` 新语义。
- `plan-mode`：将规划和执行改为显式模式切换，移除待执行计划门禁及自动执行入口，保留工具和权限边界。
- `runtime-context`：模式切换后的提醒周期及执行上下文不再依赖有效计划消费。
- `session-persistence`：恢复规划会话后允许仅切回执行模式，不自动续跑旧任务。
- `system-prompt`：模式说明与提示不再将 `/do` 描述为自动执行计划。

## Impact

- 预计新增 `src/mewcode/commands/`，迁移 `terminal/commands.py` 中的注册、解析与帮助逻辑；调整 `app.py`、`session.py`、`prompts.py` 及 `terminal/` 的适配、状态栏和补全菜单。
- 记忆查看需要专用读取接口，不能复用会建目录、加锁或重建索引的维护接口；会话列表复用已有扫描能力。
- 更新命令、规划、提醒、存档恢复和终端测试，以及 README、验收清单和本次 tmux 证据。无新增外部服务或运行时依赖。
