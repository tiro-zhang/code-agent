## Why

终端入口已经具备完整代理执行能力，但长文本输入与阅读、执行过程追踪、修改审阅和会话切换受到终端布局与输入方式限制。增加本机浏览器入口，使用户可以围绕聊天完成任务，并在同一页面查看过程、处理审批和继续历史会话。

## What Changes

- 新增 `mewcode --config <path> --web` 启动方式，一次启动绑定当前真实项目根目录，仅提供本机浏览器访问；原终端启动方式继续可用。
- 提供以聊天为中心的三部分界面：会话列表、聊天与多行输入、可收起的任务详情与审批面板；支持流式 Markdown、代码高亮与复制、按会话保留草稿。
- 支持项目内普通会话的新建、列表、历史阅读和显式继续；浏览历史不触发模型、MCP 或旧任务执行。保留现有会话存档的单写入者约束。
- 新增独立 Web 接口与会话运行管理层，复用 `ChatSession`、Agent、工具、权限、存档和命令定义，提供结构化状态、工具结果、局部 diff、授权决定及取消入口。
- 本次 Web 服务内，同一项目只允许一个会话占用执行槽；活动子任务、自动接续、恢复维护与取消收尾均纳入占用。其他会话可以浏览和起草，提交冲突明确拒绝，不自动排队。
- 运行任务独立于浏览器连接；刷新或切换页面重新同步状态，不重复提交。服务重启后只展示已保存历史，经用户显式继续后恢复上下文，等待新的明确任务。
- 增加 Web 的访问边界、重连、幂等提交、审批关联、历史投影与资源清理验证；同步启动说明、验收清单和浏览器／tmux 验收材料。

第一版面向个人、本机、单项目使用。多用户账号、远程监听、多项目管理、跨会话并行执行、在线文件编辑器，以及团队管理专用页面不在本次范围内。串行约束针对本次 Web 服务，不声称阻止独立 CLI 进程或其他程序修改项目。

## Capabilities

### New Capabilities

- `web-interface`: 本机 Web 启动与访问、聊天与会话导航、结构化任务展示、可信审批、串行执行、连接恢复、历史阅读和服务关闭合同。

### Modified Capabilities

无。终端专属交互、斜杠命令、模型历史恢复和工具权限合同继续适用；新的浏览器导航、展示状态与执行槽规则由 `web-interface` 增量规格定义。公共生命周期提取属于兼容性重构，不改变终端行为。

## Impact

- 入口与应用层：`src/mewcode/cli.py`、`app.py`，新增界面无关的运行生命周期模块和 `src/mewcode/web/`；不把 Web 路由集中写进入口文件。
- 核心接点：`session.py`、`tasks/`、`commands/`、`permissions/runtime.py`、`sessions/`、MCP 生命周期；通过适配器复用已有合同，新增只读展示投影与状态传输。
- 前端与分发：新增前端源码、构建锁文件和随 Python 包分发的静态资源；设计选择 FastAPI／Uvicorn、React／TypeScript／Vite，以及 HTTP 操作接口与 SSE 事件流。最终依赖版本由实现阶段兼容性验证和锁文件确定。
- 存储：继续使用现有项目 JSONL 存档，不新增业务数据库；浏览器草稿与服务内有界事件缓存独立于模型工作历史。
- 验证与文档：新增 API、运行状态与浏览器测试；回归现有 Python 测试和真实终端流程，更新 `README.md`、`checklist.md`，在 `docs/validation/web-interface/` 记录本次实施验收。
