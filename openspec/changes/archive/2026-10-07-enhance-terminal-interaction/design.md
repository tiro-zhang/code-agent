## Context

动机与五项范围见 [proposal.md](proposal.md)。本变更同时调整输入生命周期、详情数据模型及增量排版，满足跨模块和输入隔离复杂度条件，因此保留完整设计文档。

现有实现的关键约束：

- `TerminalController.write/_flush` 将完整行写入终端回滚区，未完成行在活动区域预览；`EnhancedTerminal` 使用非全屏 `prompt_toolkit` 应用。已经输出的历史正文不适合就地折叠或语义重排。
- `MarkdownStyle` 目前按行着色，`DetailStore.text` 拼接参数／结果 JSON，`_details_text` 每次对整段文本重新分页。此前只读复现中，24 条约 1.4 MB 的模拟结果产生 768 页；这说明需要先按调用定位，再加载当前调用的展示。
- `TerminalState.begin_task` 替换当前详情；`EnhancedTerminal.set_phase` 清空聊天与授权缓冲，运行期普通按键被忽略。自动接续通过 `save_draft/readline` 保存并恢复快照；新增运行中编辑后，旧快照不能覆盖最新草稿。
- `app.py` 的普通任务和自动接续均启动一个主执行段，手动 `/compact` 走独立维护路径；后台父任务最终结束与主执行段结束已经分开。已有输出降噪、真实用量、权限及取消行为应复用。
- 仓库测试覆盖括号粘贴跨阶段、授权抢占、窄屏、草稿与光标、plain 管道、Skill／团队通知。此次修改须更新改变的合同，并继续验证这些已有边界。

## Goals / Non-Goals

**Goals:**

- 让展示历史、当前运行控制和用户草稿各自拥有明确生命周期，历史浏览不能改变当前取消对象或统计。
- 用有界的结构化展示快照支持调用选择、格式化正文、搜索和跨轮浏览，避免每次刷新拼接全部结果。
- 保持按到达顺序的增量输出；只在尚未提交的活动区完成 Markdown 解析，不重印历史。
- 对正常、失败、取消、容量不足和阶段竞争给出可验证行为。

**Non-Goals:**

- 全屏 TUI、主对话就地折叠、历史正文整体重排、鼠标导航、重启后的 F2 历史恢复。
- 运行中发送或排队追问、打断后自动提交、由草稿触发权限决定。
- 通过详情读取磁盘缓存、重新执行工具、生成模型摘要或持久化思考。
- 更改供应商协议、Agent 调度预算、权限范围、真实会话存档格式及团队生命周期。

## Decisions

### 1. 继续使用非全屏主对话，F2 承担结构化浏览

主对话保留成功调用摘要、独立异常和模型正文。F2 使用单面板层级浏览，适配宽窄终端，不增加多个输入读取者。

```text
Transcript --> F2 --> Call list --> Call detail
                       |               |
                       v               v
                    Turn list      Raw / Search
                       |
                       v
                    Call list
```

首次 F2 打开当前／最近轮次调用列表；`t` 打开轮次选择，列表 ↑／↓ 选择、Enter 确认，详情 PgUp／PgDn 翻页。Esc 返回上一级，顶层 Esc 或任何层 F2 关闭。Tab 保留调用／思考分类切换。调用列表 `/` 打开搜索、`e` 切换异常筛选；调用详情 `/` 搜索保留正文、`n/N` 定位下一／上一匹配，`r` 切换原始 JSON。搜索使用独立小缓冲，Esc 先退出搜索；所有快捷入口按所在页面提示，不进入聊天或授权。

默认列表遵循原始调用顺序，完成与失败更新同一行；异常筛选不重排原始记录。选择用轮次 ID／调用 ID 保存，详情用原始逻辑行和字符偏移作锚点，宽度变化时重新计算所在页。新结果不跳转焦点。授权抢占关闭普通详情并保留浏览状态，审批后由用户重新按 F2 打开。

考虑过继续使用拼接 JSON 分页，定位成本无法改善；也考虑过主对话内联折叠，但需要重建可重排 transcript。已按用户选择采用独立 F2 浏览。

### 2. 将可浏览历史与活动状态分开

新增 `terminal/history.py` 管理有界轮次与调用记录；`state.py` 继续拥有当前真实阶段和用量，`projection.py` 继续决定哪些事件进入主对话。浏览选中历史不能把旧 `TerminalState` 替换为当前状态。

展示轮次沿用一次主执行段的边界，普通提交保存用户实际输入的脱敏摘要；提示词命令使用用户原始命令，不展示内部展开文本。自动接续记录为带父任务来源的“自动接续”轮次，不伪造新用户输入；阶段结束标为执行段结束，父任务最终状态另行说明。维护、只读命令、后台通知本身不新建轮次，子 Skill 调用按已有父子关联归入所属主段。此选择沿用当前 `begin_task/finished` 边界，避免改变任务调度及父预算。

应用在开始主执行段时传入问题摘要、开始时间和接续来源；当前 `run_id` 到达后绑定展示身份。调用键包括主段、子来源及调用标识，不能仅使用重置后的 `#1`。重复／迟到事件只更新可确认归属的记录，不新建轮次或覆盖当前任务。

当前轮次加最多 10 个已结束轮次共享正文预算 8 MiB，按脱敏后的 UTF-8 字节计数；真实 API 思考总计最多 256 KiB，单条工具结果正文最多 64 KiB。为避免参数副本膨胀，单条参数展示快照同样最多 64 KiB，截断显式标记。先移出最旧已结束轮次正文，再移出当前轮次最早正文；保留数量范围内的身份、状态、引用和移出原因。第 11 个已结束轮次使最旧轮次退出索引。

字节计数增量维护；原始正文仅存一份，格式化正文按选中调用懒生成并计入 8 MiB 预算，失效立即释放。索引元信息单独上限 1 MiB、每轮最多 1024 条调用索引，超限保留累计数量及“部分索引已移出”标记，先移出历史、再处理当前最早索引。搜索／分页缓存另有合计 256 KiB 上限，只缓存当前视图并按内容版本、宽度和视图种类失效。活动段另保留最多 4096 个已见调用身份的精确 SHA-256 摘要，摘要与集合开销计入 1 MiB 元信息预算，段结束即释放；不用概率过滤器判断新调用。身份跟踪达到上限后不重建无法确认的索引，显式展示“累计至少 N 次调用”及无法确认身份的省略事件数量，不能冒称重复事件已去重或累计数完整。上述限制仅影响展示，不修改 Agent 消息、会话结果或真实工具统计。

`/clear` 保留历史和选择，`/reset` 清除展示历史；退出释放全部新增缓存。`/status` 继续聚焦当前／最近一段，不倾倒 10 轮全文。没有使用已有 JSONL 作为 UI 数据源，因为它会扩大到跨会话浏览、补读及思考持久化问题。

### 3. 格式化单次工具快照，保留原始核对入口

新增 `terminal/result_view.py` 提供纯展示转换，输入为已有脱敏参数、结果和截断元信息，输出为分区文字与可分页行。`details.py` 负责有界正文存取，不再把全部调用组装成一个巨型字符串供 F2 使用；保留当前任务文字接口供 plain `/status` 兼容。

| 结果 | 默认展示 | 边界 |
| --- | --- | --- |
| `read_file` | 路径、已有起止行元信息、内容正文 | 不给正文加可复制行号，不自动读取缺失内容 |
| `execute_command` | 命令、退出码、stdout、stderr 分区 | 解码字符串换行，不把成功退出解释为业务验收通过 |
| `edit_file` | 当前调用 old_text/new_text 的局部 diff | 标明仅依据调用参数，参数缺失或截断时不声称完整差异 |
| `write_file` | 路径、写入内容快照与实际结果 | 预览内容与执行结果状态分开 |
| 搜索／MCP／其他结构化数据 | 已有字段及文本块，可读缩进 | 外部 path 不冒充真实本地路径，不拉取资源 |

先在结构化值层脱敏和处理不可信字符，再形成可读视图；字符串中的实际换行允许展示，控制字符仍转义。原始 JSON 是已有快照的安全原文，若截断导致无法解析，直接显示保留片段及原因，不能补全或猜测。UI 先按结果类型选择格式化器，失败时回退安全原文。

异常筛选依据真实结果字段，包含失败、拒绝、取消、超时、截断、受限及副作用未知，不用自然语言猜测成功。搜索只对选定轮次索引或当前调用保留正文做字面匹配；不搜索未载入文件，不默默把截断片段当全文。

### 4. 持久聊天草稿与阶段输入权限分离

`EnhancedTerminal.chat` 持续保存唯一下一条草稿；阶段切换仅改变可编辑性、焦点及按键代次，不能再统一清空聊天缓冲。只有实际提交消费、空闲 Ctrl+C 清草稿和退出会清掉对应内容。授权仍使用独立 `answer`，详情搜索使用独立缓冲。

| 底层阶段／视图 | 聊天编辑 | Enter | Ctrl+C |
| --- | --- | --- | --- |
| 空闲聊天 | 可编辑 | 有输入接收者时提交一次；补全菜单仍先确认 | 非空清草稿，空草稿退出 |
| 工作运行／压缩 | 可编辑 | 不提交、不排队，提示结束后发送 | 取消当前操作，保留追问 |
| 授权 | 聊天冻结，审批可输入 | 仅处理当前请求 | 取消所属操作，保留聊天草稿 |
| F2／搜索 | 聊天冻结 | 仅用于选择、浏览或搜索 | 沿底层阶段处理 |
| 正在停止／启动／控制指令／关闭 | 聊天冻结 | 不提交聊天 | 沿既有阶段收尾 |

发送操作先固定本次文档值并清空下一条草稿，再切入运行；运行期的新字符只编辑下一条草稿。Enter 的接受条件同时检查当前空闲阶段、输入 Future 就绪及按键代次，运行期已接收 Enter 不留到空闲回放。保留 `_PasteBoundary` 和阶段队列清理，跨代未完成粘贴完整丢弃；清理按键队列不再等同于清除文档。

增强终端自动接续沿用唯一草稿，不在 `readline` 用旧 `_saved_draft` 覆盖它。plain 暂存／恢复逻辑保持，应用仍优先处理已提交输入再接受后台唤醒。新增运行中草稿不产生队列、控制命令、历史条目或模型请求；仅当后续空闲明确提交后才进入既有分发链。

### 5. 增量 Markdown 只重排未提交的可见区

扩展 `markdown.py` 为有界的行／块状态解析器，继续输出 `FormattedText`。保持“可见预览”和“不可重复追加的已提交片段”分离；无完整语法时先展示原文，完整粗体／行内代码识别后在提交前转换样式，代码围栏内不解析行内语法。支持子集包括既有标题、列表、围栏和 diff，以及 `**`／`__` 粗体、反引号行内代码和管道表格；其他 Markdown 保留原文。

表格候选表头在活动区可见，最多前瞻一条分隔行；确认表格后由表头、列数与当前可用宽度确定列宽，各数据行到达即逐行提交。单元格按终端显示宽度换行，识别转义和反引号范围内的竖线。若各列无法获得可辨读最小宽度，转为“表头：单元格”的分项布局；窗口变化只影响后续行，每个分项自带表头，保持关联。

未完成行、候选表头与围栏元信息设明确有界缓存；候选缓冲达到 64 KiB 即原文输出并退出该候选解析，避免长行阻塞或无界增长。请求结束、中断及角色切换时刷新全部已接收预览并重置语法状态，避免代码样式吞入系统提示。plain 直接沿用安全原文路径。优先使用已有库的宽度和样式能力，不新增渲染依赖；完整 Markdown 解析器会扩大本轮语法与流式兼容成本。

### 6. 常驻上下文来自活动会话，提示来自同一操作状态

`TerminalController.sync_session` 及应用初始化传入真实模型和有效工作根，状态格式化时统一脱敏、主目录缩写和中间省略。底栏按模式／权限／阶段、模型、目录的优先级分配宽度，运行时另显示请求次数与耗时；授权与小高度布局优先给决定和导航留空间。完整值沿用 `/status`。

按同一阶段和视图状态生成按键过滤器与提示，避免“运行中 Enter 发送”或不可用 Ctrl+B 的误导。F2 的历史选择只影响浏览标题，不影响常驻模型、工作根、当前模式、统计或取消归属。不把图中未由配置提供的模型推理档位猜测为实际设置。

## Risks / Trade-offs

- 草稿保留后，旧的“清空一切”阶段切换测试会改变 → 区分合法草稿保留与控制键／授权残留清除，覆盖完成、取消、授权和自动接续的相邻事件。
- 每轮各自限制会把总内存放大，解析副本也可能绕过预算 → 使用跨轮统一计数，加上有界元信息和当前视图缓存；测试 UTF-8 中文、思考、原始／格式化视图来回切换。
- 运行中输出可能频繁打断详情或使搜索重做 → 浏览选择独立，正文按版本缓存，按稳定位置锚点重排；没有内容版本变化时不重建整轮文本。
- 自动接续与父终态不同 → 明确显示执行段及接续来源，父终态按已有事件辨认；不以模型自然结束冒充目标验收完成。
- 表格判断需要有限前瞻，历史无法语义重排 → 候选原文即时预览，确认后逐行提交；把终端回滚区限制写进用户文档与测试。
- 文件结果参数可能已截断或缺失 → 可读视图显式显示不完整状态，保留安全原文；不通过额外工具调用补齐。
- 当前只有部分终端与服务可在本机验证 → 本轮实际 tmux/PTY 证据与自动化覆盖分别记录，未执行项明确原因。

## Migration Plan

1. 先落实展示快照、共享预算及跨轮生命周期，保持旧输出接口可用于回归；再接入 F2 列表与单调用视图。
2. 调整草稿生命周期和状态提示，复验既有权限、取消、自动接续及 plain 合同；接入增量 Markdown 和宽窄屏布局。
3. 按任务清单完成自动化、真实模型 tmux、实际 PTY 与构建，更新 README、验收清单及脱敏证据。规格只在实施验证后通过正常 OpenSpec 同步／归档流程进入主规格。
4. 无持久数据迁移。回退终端实现会丢弃当前进程新增展示历史，但不改变原会话 JSONL、工具结果、权限或工作文件。
