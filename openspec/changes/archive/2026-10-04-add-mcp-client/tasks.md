## 3. 多 Server 连接与生命周期

- [x] 3.1 实现每 Server 独立生命周期所有者和缓存记录，两类 transport 使用相同 manager 调用接口；以两次任务仅一个 stdio 进程和同 task 进入／退出 SDK 上下文验证。
- [x] 3.2 实现最多 4 个并行准备、每 Server 15 秒完整发现期限及工具分页；用一快一慢、空列表、无工具能力、重复 cursor 和半途断连验证完整提交与隔离。
- [x] 3.3 实现 starting/ready/failed/closed 状态及等待者失败通知；验证进程退出或会话失效只影响所属 Server、后续快速 mcp_unavailable、不重连，普通业务错误不破坏可用连接。
- [x] 3.4 实现单次调用 30 秒期限、本地任务取消与远端取消适配，并接入 HTTP 单请求生命周期；验证授权等待不计时、远端 timeout_seconds 不改本地期限、新旧协议 GET 恢复不延长期限、取消后不再恢复且不关闭共享连接或影响其他请求。
- [x] 3.5 实现幂等且独立的退出清理、5 秒总关闭预算（3 秒正常阶段、剩余时间强制回收）；测试 owner／SDK 退出不响应取消时仍有界报告失败且不阻塞其他 Server／Provider，正常启动取消和重复取消不泄漏进程、流或等待者。
- [x] 3.6 实现 stdio stderr 有界持续处理及安全错误归一化；用大量 stderr 输出和含测试秘密的异常验证无管道阻塞、无协议混读及无凭据原文泄漏。
