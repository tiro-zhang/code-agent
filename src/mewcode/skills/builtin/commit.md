提交目标：{{args}}

1. 阅读当前项目约定，检查实际 Git 状态、暂存和未暂存差异及未跟踪文件。目标为空时，以当前用户明确要求提交的改动为范围。
2. 核对改动与目标、已有验证结果和敏感文件；不自动扩大暂存范围，不覆盖用户的其他工作，不提交密钥或临时产物。
3. 根据实际差异拟定符合项目惯例的提交说明。只有当前用户任务已经授权创建提交时，才通过获准的命令暂存目标并提交；否则说明拟提交内容和缺少的授权。
4. 检查命令真实结果与提交后状态，报告提交标识、包含范围和验证。无 Git、没有改动、工具交集不足、授权拒绝或提交失败均如实说明，不声称已成功。

所有操作受当前模式、全部激活白名单、项目手写规则和权限约束。加载 SOP 不自动运行命令或授予授权。
