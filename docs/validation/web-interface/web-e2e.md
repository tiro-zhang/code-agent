# 本轮 Web 真实模型与浏览器验收

日期：2026-10-07。临时项目 `/private/tmp/mewcode-web-e2e-20261007`，专用 tmux 会话 `mewcode-web-e2e`，Chrome 浏览器，端口 8877。使用仓库现有已授权 `.env` 的 OpenAI 兼容模型 `ark-code-latest`；不复制配置或启动链接凭据。

实际启动命令为仓库 `.venv/bin/mewcode --config [repo]/.env --web --port 8877`，工作目录为上述临时项目。文件读取、编辑和长命令审批均仅作用于临时项目，每次选择“允许本次”。本报告记录真实服务和真实供应商；受控 API fixture 的多标签、窄屏及故障测试单列于 [前端报告](frontend-report.md)。

## 实际操作与结果

| 场景 | 本轮结果 |
| --- | --- |
| 启动、浏览、新建、显式继续 | 页面显示真实临时项目；创建空存档后只读浏览，明确继续后进入可以开始，不自动发送输入 |
| README 读取审批和流式回复 | 审阅目标、完整参数、内容和授权范围，允许本次 read_file；实际答出 Python 3.11、uv sync、本机 Web 启动及 `WEB_LOCAL_42` |
| 按标签页保存草稿 | 输入“读取后准备编辑的草稿，刷新也应保留。”后刷新，草稿保持；原输入与助手回复各一份 |
| 真实编辑及局部 diff | 模型先 read_file，再申请 edit_file；审批展示 before-web → after-web，分别允许本次 |
| 编辑批准后立即刷新 | 工具继续执行，页面恢复同一任务，最终答复仅一份；独立检查文件精确为 `after-web\n`，存档只有一个 edit_file 调用 |
| 实际运行中停止 | 明确提交且一次批准 `sleep 120`；观察 execute_command 已开始后点击停止，等待清理后回到可以开始，结果为 cancelled，副作用未知提示保留，不宣称取消会回滚操作 |
| 服务重启和旧凭据 | Ctrl+C 结束旧服务，再启动新实例；原页面刷新后只显示需要本次启动链接，不能读取项目数据；新链接认证后明确提示服务已重启、旧操作不会重发 |
| 重启后的只读历史 | 读取、编辑及取消证据仍可查看；取消轮显示未完整提交和孤立结果提示，不伪造完整工具交互；服务未加载运行会话 |
| 显式继续不重放 | 重启前 30 条记录，显式继续后 31 条；唯一新增为 session_resumed，模型工作轮、工具和维护数量均未增加 |
| 恢复后新对话 | 明确发送“不要调用任何工具，仅依据已恢复的对话回答上次编辑结果”；正确回复 `after-web` 和 `WEB_RESUME_OK`，无新增工具 |
| 服务清理 | 本次专用 tmux 服务完成验收后关闭；不保留供用户误用的测试服务或访问凭据 |
